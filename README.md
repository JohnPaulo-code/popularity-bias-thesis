# Quantifying the Limits: Post-Processing Popularity Bias Mitigation Under Varying Base-Model Bias

M.Sc. thesis project, Data Analytics, Stiftung Universität Hildesheim.
Author: John Paulo

## Overview

Recommender systems tend to over-recommend popular items. This project tests how far post-processing re-rankers can reduce that bias when the base model is already biased to different degrees.

**Main finding:** there is a structural ceiling on long-tail exposure. It declines steadily as base-model bias increases, and re-ranking alone cannot remove it.

## Experimental setup

| Component | Details |
|---|---|
| Datasets | MovieLens-1M, Amazon Books |
| Base models | BPR, NeuMF, LightGCN |
| Re-rankers | Binary xQuAD, Smooth xQuAD, FA*IR |
| Bias levels (alpha) | 1.0, 1.2, 1.5, 1.75, 2.0 |
| Random seeds | 42, 123, 456 |
| Method choices | Fixed long-tail definition, Nash bargaining with relative improvement scoring |

An additional single-seed BPR appendix extends the experiments to negative bias directions (alpha 0.5 and 0.75).

## Supplementary analyses

- Zone Migration
- Mitigation Efficiency
- Relative APLT Improvement
- Cross-Architecture Absolute Gains
- Marginal Sensitivity

## Installation

```bash
git clone https://github.com/JohnPaulo-code/popularity-bias-thesis.git
cd popularity-bias-thesis
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Data

The raw datasets and the large intermediate files are not included in this repository. Download the raw data and place it as follows:

```
original_data/
├── ml-1m/ratings.dat      # MovieLens-1M
└── ratings_Books.csv      # Amazon Books (ratings only)
```

- MovieLens-1M: https://grouplens.org/datasets/movielens/1m/
- Amazon Books ratings: https://jmcauley.ucsd.edu/data/amazon/ (check the source's terms of use)

The biased datasets (one per alpha level) are generated by the scripts in `data_preparation/`. Candidate lists (`.pkl`) and per-user metrics (`.json`) are created when you run the experiments and are not stored in this repository.

## Usage

Run the steps in this order:

```bash
# 1. Prepare the filtered and biased datasets
python data_preparation/YOUR_SCRIPT.py

# 2. Train the base models and generate candidates
python cross_model/YOUR_SCRIPT.py

# 3. Apply the re-rankers and compute metrics
python sensitivity_analysis/YOUR_SCRIPT.py
```
